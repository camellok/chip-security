# ex02：调试观察与反复锁定/解锁

本例程沿用 ex01 的功能模块、参数和 OTP 配置，专门比较锁定与解锁时的调试读取。DriverLib 保持原样。

## 最小运行逻辑

模块计算 `output = input * 3 + 7`，输入1～9循环。代码在 Zone1 sector4，参数 `{3,7}` 在 Zone1 sector5，两个观察量 `g_module_input`、`g_module_output` 在非安全 RAM。

LED 固定每250 ms 翻转。Zone1 解锁时调用模块并输出结果；锁定时主动暂停模块调用，输入输出保持原值。暂停用于把 CPU 留在普通 APP，便于调试观察，不能作为 RAM 受到保护的证据。

KEY 根据当前实际状态切换锁定/解锁。按住至少300 ms 后松手，程序打印请求及操作后的状态。按住期间轮询等待，LED 也会暂停翻转。

## 构建与配置

导入 `ex02_dcsm_debug` 并重新生成 IDE 构建文件。已保留对应 launch 配置；它继承密码和自动解锁命令，连接后可能已经解锁。以当前 `Z1_CR` 为准，不依赖较早的启动日志。

本版本与 ex01 使用相同的新 Zone1 ZSB2：`0x007A0060`，三个 LINKPOINTER 均为 `0x1FFFFFFE`，sector4/5 均属于 Zone1。切换 ex01/ex02 不需要再次更新 OTP。

使用默认构建输出 `Debug/ex02_dcsm_debug.hex`，不额外转换 HEX。该文件包含 OTP 配置，日常仅更新程序时必须在下载工具中明确排除 USER OTP；调试器加载 ELF 时也应核对实际下载范围。工具若不支持排除 OTP，不应直接执行仅更新程序的下载。一次性 OTP 准备见[简要回归表](../../docs/REGRESSION_EX00_EX02.md)。

## 简短演示

1. 进入调试后先读当前状态。已解锁时，串口结果正常，LiveView 中输入输出更新；直接读 `0x00614000` 应为32位数值3、7。
2. 按 KEY 锁定。确认 UNSECURE 为0，输入输出停止更新，LED 继续闪烁；读取 sector4/5 并记录结果及调试连接是否保持。
3. 再按 KEY 解锁。确认 `Z1_CR=0x60`，参数可读、输入输出继续更新。做3轮即可完成这次简要回归。
4. 断电重启，确认恢复 secure。结果填写到[简要回归表](../../docs/REGRESSION_EX00_EX02.md)。

读取时同时记录安全状态，排除工具缓存或自动解锁的干扰。受限读取返回零，不表示 Flash 内容被清零。

## 寄存器观察

以下为32位寄存器的字节地址。

| 寄存器 | 地址 | 检查内容 |
| --- | --- | --- |
| Z1_CR | `0x00039430` | bit6 ARMED、bit5 UNSECURE；当前驱动以掩码 `0x60` 全部置位判断解锁 |
| B0_Z1_GRABSECTR | `0x00039434` | sector4 的 `[9:8]`、sector5 的 `[11:10]` 均为 `01` |
| B0_Z2_GRABSECTR | `0x00039484` | 同样两组字段均为 `10` |
| B0_SECTSTAT | `0x000394A4` | 分别记录 sector4/5 的归属，不将归属与解锁混为一谈 |

## 补充读取与历史记录

2026-10-22 开发者确认新模块 / ZSB2 版本简要板级回归通过：3轮锁定与解锁全部成功。锁定时 `Z1_CR=0x08`，sector4 代码与 sector5 参数读回零；解锁时 `Z1_CR=0x60`，代码正常可读，参数为3、7。输入输出锁定暂停、解锁恢复，LED 及调试连接正常；断电重启恢复 secure，按键解锁后计算恢复。锁定判据为 UNSECURE=0，不要求寄存器整体必须为旧记录中的 `0x00`。该结果覆盖本轮观察范围，不代表完整安全性测试。

应用层的 `Prepare_Zone1_Unlock()` 先读取 OTP 头部、计算当前 ZSB、读取其配置，再调用原始解锁 API。该试验不写 OTP，未修改驱动库。根因、最小必要读取和 TI F280025C 的对应行为仍待确认，详见 [DCSM_ERRATA.md](../../DCSM_ERRATA.md)。

旧 SPWM / 首个 ZSB 版本已由开发者完成10轮锁定/解锁：锁定时 `Z1_CR=0x00`、正弦表读回零且调试连接保持；解锁后 `Z1_CR=0x60`、读取正常，断电恢复 secure。这是本次调整前的记录，不替代新模块和新配置的板级回归。
